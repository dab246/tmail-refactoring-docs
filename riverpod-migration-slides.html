Code — Controller Migration

GetxController → AsyncNotifier

Before — GetX

class SpamReportController
    extends GetxController {

  final spamState = Rxn<SpamReportState>();
  final unreadCount = RxInt(0);

  @override
  void onInit() {
    super.onInit();
    _loadSpamState(); // side-effecting onInit
  }

  Future<void> _loadSpamState() async {
    final result = await
        _interactor.execute();
    result.fold(
      (f) => log('failed'),
      (s) { spamState.value = s.state; },
    );
  }
}

After — Riverpod

class SpamReportNotifier
    extends AsyncNotifier<SpamReportState> {

  @override
  Future<SpamReportState> build() async {
    // build() IS onInit() — clean & testable
    final result = await
        ref.read(spamInteractorProvider)
           .execute();
    return result.fold(
      (f) => throw f,
      (s) => SpamReportState(
        data: s.state,
        unreadCount: s.unreadCount,
      ),
    );
  }
}

final spamReportProvider =
  AsyncNotifierProvider<SpamReportNotifier,
                         SpamReportState>(
    SpamReportNotifier.new);

// ThreadNotifier auto-reloads when mailbox changes — no ever() needed:
class ThreadNotifier extends AsyncNotifier<ThreadState> {
  @override
  Future<ThreadState> build() async {
    final mailbox = ref.watch(selectedMailboxProvider); // reactive dep
    if (mailbox == null) return const ThreadState();
    return _loadEmails(mailbox.id);
  }
}

test('loads emails', () async {
  final container =
    ProviderContainer(
      overrides: [
        // inject mock — only what THIS test needs
        getEmailsInteractorProvider
          .overrideWithValue(
            MockGetEmailsInteractor()
          ),
      ],
    );
  addTearDown(container.dispose);

  final n = container.read(
    threadNotifierProvider.notifier
  );
  await n.loadEmails();
  expect(
    container.read(threadNotifierProvider)
      .value?.emails,
    hasLength(5),
  );
});
Risk Management

Known Risks & Mitigations

⚠ Breaking changes on controller delete

Only delete Binding after ALL consumers migrate. Use feature flags to toggle old/new.

⚠ keepAlive state stale after logout

All session providers depend on sessionProvider. On logout: sessionProvider = null → cascade invalidation.

⚠ Performance regression

Use select() to watch a slice of state. Narrow Consumer scope. Profile after each phase with Flutter DevTools.

⚠ State desync in transition period

Enforce one direction: GetX → Riverpod via appProviderContainer. Never Riverpod → GetX. Code review checklist enforces this.

Rollback: Each phase is independent and reversible. Keep GetX controllers until Riverpod notifiers are stable for 2 sprints. No phase has a hard lock-in point.
